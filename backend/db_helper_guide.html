📚 Database Helper Complete Guide

Master MySQL2 CRUD Operations with Soft Delete

🎯 What is this Database Helper?

A comprehensive utility that simplifies MySQL database operations with built-in soft delete support.

🔑 Key Features:
  • Automatic soft delete handling (is_deleted flag)
  • SQL injection prevention
  • Complex WHERE conditions support
  • JOIN operations
  • Transaction support
  • Bulk operations

📊 Sample Database Table

product_id name price qty is_deleted
1 Laptop 999.99 10 0
2 Mouse 29.99 50 0
3 Keyboard 79.99 0 1
4 Monitor 299.99 15 0
⚠️ Important: is_deleted = 0 means active, is_deleted = 1 means soft-deleted

🔄 How Soft Delete Works

User requests to delete product_id = 3
System sets is_deleted = 1 (not physically deleted)
Product remains in database but hidden from normal queries
Can be restored later if needed

📋 getAll() Excludes Deleted

Purpose: Get all records from a table, automatically excluding soft-deleted records.

🔍 How it Works:

You call: getAll({ table: 'product' })
Helper adds: is_deleted = 0 automatically
SQL: SELECT * FROM product WHERE is_deleted = 0
Returns only active products

💻 Basic Example:

// Import the helper import dbHelper from './util/database/dbHelper.js'; // Get all products (excludes deleted) const products = await dbHelper.getAll({ table: 'product' }); // Result: [{ product_id: 1, name: 'Laptop', ... }, ...]
Generated SQL:
SELECT * FROM product WHERE is_deleted = 0

🎨 Advanced Examples:

1️⃣ Select Specific Columns

const products = await dbHelper.getAll({ table: 'product', selectColumns: ['product_id', 'name', 'price'] });
SQL: SELECT product_id, name, price FROM product WHERE is_deleted = 0

2️⃣ With WHERE Condition

const products = await dbHelper.getAll({ table: 'product', where: { 'price >': 100, qty: 10 } });
SQL: SELECT * FROM product WHERE price > 100 AND qty = 10 AND is_deleted = 0

3️⃣ With ORDER BY and LIMIT

const products = await dbHelper.getAll({ table: 'product', orderBy: [{ key: 'price', value: 'DESC' }], limit: 10, offset: 0 });
SQL: SELECT * FROM product WHERE is_deleted = 0 ORDER BY price DESC LIMIT 10 OFFSET 0

4️⃣ With WHERE IN

const products = await dbHelper.getAll({ table: 'product', whereIn: { product_id: [1, 2, 4] } });
SQL: SELECT * FROM product WHERE product_id IN (1, 2, 4) AND is_deleted = 0

5️⃣ Search with LIKE (OR)

const products = await dbHelper.getAll({ table: 'product', orLike: [ { key: 'name', value: 'lap' }, { key: 'description', value: 'lap' } ] });
SQL: SELECT * FROM product WHERE (name LIKE '%lap%' OR description LIKE '%lap%') AND is_deleted = 0
✅ Result: Returns array of products, automatically excluding any with is_deleted = 1

🎯 getOne() Single Record

Purpose: Get a single record, automatically excluding soft-deleted records.

💻 Basic Example:

// Get product by ID const product = await dbHelper.getOne({ table: 'product', where: { product_id: 1 } }); // Result: { product_id: 1, name: 'Laptop', price: 999.99, ... } // OR null if not found
Generated SQL:
SELECT * FROM product WHERE product_id = 1 AND is_deleted = 0 LIMIT 1

🔄 Visual Comparison:

❌ If product_id = 3 (deleted)

const product = await getOne({ table: 'product', where: { product_id: 3 } }); // Result: null

✅ If product_id = 1 (active)

const product = await getOne({ table: 'product', where: { product_id: 1 } }); // Result: { product_id: 1, ... }
💡 Key Points:
  • Returns single object or null
  • Automatically adds is_deleted = 0
  • Returns false on database error

🗑️ getAllWithDeleted() Includes Deleted

Purpose: Get all records including soft-deleted ones.

🔍 Difference from getAll():

getAll()

WHERE is_deleted = 0

Returns: Active records only

getAllWithDeleted()

No is_deleted filter

Returns: All records

💻 Examples:

1️⃣ Get All Records (Including Deleted)

const allProducts = await dbHelper.getAllWithDeleted({ table: 'product' }); // Returns: All 4 products including product_id = 3 (deleted)

2️⃣ Get Only Deleted Records

const deletedProducts = await dbHelper.getAllWithDeleted({ table: 'product', where: { is_deleted: 1 } }); // Returns: Only soft-deleted products
SQL: SELECT * FROM product WHERE is_deleted = 1

3️⃣ Get Specific Product (Even if Deleted)

const product = await dbHelper.getOneWithDeleted({ table: 'product', where: { product_id: 3 } }); // Returns: { product_id: 3, name: 'Keyboard', is_deleted: 1, ... }
⚠️ Use Case: Admin panels, data recovery, audit trails

➕ createOne() & createMany() INSERT

📝 createOne() - Insert Single Record

const result = await dbHelper.createOne('product', { name: 'Webcam', price: 89.99, qty: 20, is_deleted: 0 }); // Result: { success: true, insertId: 5, affectedRows: 1 }
SQL:
INSERT INTO product (name, price, qty, is_deleted) VALUES ('Webcam', 89.99, 20, 0)

📦 createMany() - Bulk Insert

const result = await dbHelper.createMany('product', [ { name: 'Headphones', price: 49.99, qty: 30, is_deleted: 0 }, { name: 'Speaker', price: 129.99, qty: 15, is_deleted: 0 }, { name: 'Microphone', price: 79.99, qty: 25, is_deleted: 0 } ]); // Result: { success: true, insertId: 6, affectedRows: 3 }
SQL:
INSERT INTO product (name, price, qty, is_deleted) VALUES ('Headphones', 49.99, 30, 0), ('Speaker', 129.99, 15, 0), ('Microphone', 79.99, 25, 0)

🔄 Insert Flow:

Prepare data object(s)
Call createOne() or createMany()
Helper builds INSERT query
Execute query with parameterized values
Return insertId and affectedRows
✅ Benefits:
  • createMany() is faster than multiple createOne() calls
  • All inserts happen in single query
  • Automatic SQL injection prevention

✏️ updateOne() & updateMany() Only Non-Deleted

🎯 updateOne() - Update Single Record

const result = await dbHelper.updateOne( 'product', // table { price: 899.99, qty: 8 }, // data to update { product_id: 1 } // where condition ); // Result: { success: true, affectedRows: 1, changedRows: 1 }
SQL:
UPDATE product SET price = 899.99, qty = 8 WHERE product_id = 1 AND is_deleted = 0
⚠️ Important: Only updates if is_deleted = 0

❌ What Happens with Deleted Records?

// Try to update product_id = 3 (which is deleted) const result = await dbHelper.updateOne( 'product', { price: 199.99 }, { product_id: 3 } // This is deleted! ); // Result: { success: false, affectedRows: 0, changedRows: 0 } // Because: WHERE product_id = 3 AND is_deleted = 0 (no match!)

📦 updateMany() - Bulk Update with Different Values

const result = await dbHelper.updateMany( 'product', [ { product_id: 1, price: 949.99, qty: 12 }, { product_id: 2, price: 34.99, qty: 60 }, { product_id: 4, price: 279.99, qty: 18 } ], 'product_id' // whereKey ); // Result: { success: true, affectedRows: 3, changedRows: 3 }
SQL (Generated using CASE):
UPDATE product SET price = CASE WHEN product_id = 1 THEN 949.99 WHEN product_id = 2 THEN 34.99 WHEN product_id = 4 THEN 279.99 ELSE price END, qty = CASE WHEN product_id = 1 THEN 12 WHEN product_id = 2 THEN 60 WHEN product_id = 4 THEN 18 ELSE qty END WHERE product_id IN (1, 2, 4) AND is_deleted = 0

🔄 updateMany() Flow:

Receive array of objects with different values
Build CASE statements for each column
Add WHERE IN for all IDs + is_deleted = 0
Execute single UPDATE query
Return affected rows count
✅ Why updateMany() is Better:
  • Single query instead of multiple UPDATE calls
  • Much faster for bulk operations
  • Reduces database round trips

🗑️ deleteOne() & deleteMany() Hard Delete

⚠️ WARNING: These methods permanently delete records from the database. Use with caution!

💥 deleteOne() - Permanent Delete

const result = await dbHelper.deleteOne( 'product', { product_id: 1 } ); // Result: { success: true, affectedRows: 1 } // Product is GONE from database!
SQL:
DELETE FROM product WHERE product_id = 1 LIMIT 1

📦 deleteMany() - Bulk Delete

const result = await dbHelper.deleteMany( 'product', { 'qty <': 5 } // Delete all products with qty < 5 ); // Result: { success: true, affectedRows: 2 }
SQL:
DELETE FROM product WHERE qty < 5

❌ Hard Delete (deleteOne/deleteMany)

  • Permanently removes data
  • Cannot be recovered
  • Breaks foreign key relationships
  • No audit trail

✅ Soft Delete (softDeleteOne/softDeleteMany)

  • Just sets is_deleted = 1
  • Can be restored
  • Maintains relationships
  • Keeps audit trail
💡 Best Practice: Use soft delete (softDeleteOne/softDeleteMany) instead of hard delete in most cases.

🛡️ softDeleteOne() & softDeleteMany() Recommended

Purpose: Mark records as deleted without removing them from the database.

✨ softDeleteOne()

const result = await dbHelper.softDeleteOne( 'product', { product_id: 2 } ); // Result: { success: true, affectedRows: 1, changedRows: 1 }
SQL:
UPDATE product SET is_deleted = 1 WHERE product_id = 2 AND is_deleted = 0

📊 Before & After Soft Delete:

Before:

product_id name is_deleted
2 Mouse 0

After softDeleteOne('product', { product_id: 2 }):

product_id name is_deleted
2 Mouse 1

📦 softDeleteMany()

const result = await dbHelper.softDeleteMany( 'product', { 'qty <=': 0 } // Soft delete out-of-stock products );
SQL:
UPDATE product SET is_deleted = 1 WHERE qty <= 0 AND is_deleted = 0

🔄 Complete Soft Delete Lifecycle:

Active Record (is_deleted = 0)
softDeleteOne() → Sets is_deleted = 1
Hidden from getAll() queries
Still visible in getAllWithDeleted()
Can be restored using rawQuery

♻️ Restoring Deleted Records:

// Method 1: Using rawQuery await dbHelper.rawQuery( 'UPDATE product SET is_deleted = 0 WHERE product_id = ?', [2] ); // Method 2: Create a restore service function async restore(id) { const result = await dbHelper.rawQuery( 'UPDATE product SET is_deleted = 0 WHERE product_id = ?', [id] ); return result; }
✅ Soft Delete Benefits:
  • Data is recoverable
  • Maintains data integrity
  • Audit trail preserved
  • Safer than hard delete
  • Can analyze deleted data later

🚀 Advanced Features

1️⃣ JOINs

const orders = await dbHelper.getAll({ table: 'orders', selectColumns: [ 'orders.*', 'customers.name as customer_name', 'products.name as product_name' ], joinArray: [ { join_type: 'LEFT', table: 'customers', condition: 'orders.customer_id = customers.customer_id' }, { join_type: 'INNER', table: 'products', condition: 'orders.product_id = products.product_id' } ] });
SQL:
SELECT orders.*, customers.name as customer_name, products.name as product_name FROM orders LEFT JOIN customers ON orders.customer_id = customers.customer_id INNER JOIN products ON orders.product_id = products.product_id WHERE orders.is_deleted = 0

2️⃣ GROUP BY & HAVING

const summary = await dbHelper.getAll({ table: 'orders', selectColumns: [ 'customer_id', 'COUNT(*) as order_count', 'SUM(total) as total_spent' ], groupBy: ['customer_id'], having: 'order_count > 5' });
SQL:
SELECT customer_id, COUNT(*) as order_count, SUM(total) as total_spent FROM orders WHERE is_deleted = 0 GROUP BY customer_id HAVING order_count > 5

3️⃣ Transactions

// Start transaction const connection = await dbHelper.beginTransaction(); try { // Multiple operations await connection.query('UPDATE accounts SET balance = balance - 100 WHERE id = 1'); await connection.query('UPDATE accounts SET balance = balance + 100 WHERE id = 2'); // Commit if all successful await dbHelper.commitTransaction(connection); } catch (error) { // Rollback on error await dbHelper.rollbackTransaction(connection); }

4️⃣ Raw Query (When You Need Custom SQL)

// Complex query not supported by helper const result = await dbHelper.rawQuery( `SELECT p.*, (SELECT COUNT(*) FROM orders WHERE product_id = p.product_id) as order_count FROM products p WHERE p.is_deleted = 0` );

5️⃣ Complex WHERE with Multiple Conditions

const products = await dbHelper.getAll({ table: 'product', where: { 'price >=': 50, 'price <=': 500 }, orWhere: [ { key: 'category', value: 'Electronics' }, { key: 'category', value: 'Computers' } ], whereIn: { brand: ['Sony', 'Samsung', 'LG'] }, whereNotIn: { status: ['discontinued', 'recalled'] }, orLike: [ { key: 'name', value: 'pro' }, { key: 'description', value: 'pro' } ] });
SQL:
SELECT * FROM product WHERE price >= 50 AND price <= 500 AND (category = 'Electronics' OR category = 'Computers') AND brand IN ('Sony', 'Samsung', 'LG') AND status NOT IN ('discontinued', 'recalled') AND (name LIKE '%pro%' OR description LIKE '%pro%') AND is_deleted = 0
💡 Key Takeaway: The helper automatically combines all conditions with AND, and adds is_deleted = 0 at the end!
